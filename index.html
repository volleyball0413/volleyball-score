GitHub Pagesでリンク共有する方法

このアプリはサーバー不要で動くため、GitHubに投稿するだけで即座にWebアプリとして無料公開できます！

  1. GitHubで新しいリポジトリを作成
    GitHubで「New repository」を押し、名前（例: volley-score）を入力して作成します（Publicを選択）。
  2. このアプリのファイルをアップロード (Push)
    index.html, style.css, app.js をリポジトリにアップロードします。
  3. GitHub Pagesを有効化する
    リポジトリの Settings ➔ Pages を開き、Branch を「main」にして「Save」をクリックします。
  4. 発行されたURLをチームに共有！
    1分ほどで専用のURL（例: https://ユーザー名.github.io/volley-score/）が発行されます。そのリンクをLINE等で送るだけで、全員がスマホで使えます！
💡 オフライン対応: 一度ブラウザで開けば、体育館で電波が繋がりにくくても端末内に保存（localStorage）され、問題なく記録できます。
