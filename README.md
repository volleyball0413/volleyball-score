# 🏐 VolleyScore (バレーボール スコア＆スタッツ記録アプリ)

バレーボールの試合記録（アナリスト・マネージャーの手書きノート）をブラウザ上で完全再現し、リアルタイムにスコア・ジグザグ推移・スタッツ（サイドアウト率・ブレイク率・選手別W/L）を自動集計できるWebアプリケーションです。

サーバー契約や面倒な環境構築は不要で、**GitHubにアップロードしてGitHub Pagesを有効化するだけで、専用リンク（URL）をチームメンバーに共有して誰でもスマホやPCから使えます。**

---

## 🌟 主な機能

1. **スッキリ使いやすい4つの統合タブ (NEW!)**
   - **📝 記録・入力**: 大きなボタンで片手タップ記録、選手交代、Undo。
   - **📈 ジグザグ推移**: 手書きノートを完全再現。丸数字と名前が線の外側に美しく並び、タップでいつでも修正可能。
   - **📊 スタッツ集計**: サイドアウト率、ブレイク率、ローテーション別W/L、選手別スタッツ。
   - **⚙️ 試合・設定・名簿**: 試合の保存・一覧、試合設定、選手登録、バックアップが1つのタブにスッキリ集約！

2. **試合の途中でも自由にラリーを編集・修正できる (NEW!)**
   - 試合の途中や終了後でも、過去のラリーの「✏️ 編集」ボタン（またはジグザグノートの文字・丸をタップ）を押すだけで、いつでも内容を修正可能！
   - 得点チーム、選手、プレー種別（SP, SA, SPM, SM等）、メモを書き換えると、**その後の全スコア・ローテーション・サーバー・スタッツが一瞬で自動再計算されます**。
   - 不要なラリーの削除も可能です。

3. **試合データの保存・履歴管理 (NEW!)**
   - ワンタップで現在の試合データをブラウザ内に完全保存。
   - 過去の試合一覧からいつでも「開く」を押して、過去の試合のジグザグ推移やスタッツを振り返ることができます。
   - **専用共有リンクのコピー**: LINE等でリンクを送るだけで、相手のスマホでもその試合が自動保存されて閲覧できます。

4. **チーム選手登録 (名簿の永久保存)**
   - 選手名や背番号を専用フォームから簡単登録。
   - 試合をリセットしても選手名簿はブラウザに安全に保存され続けます。

5. **手書きノート完全再現サンプルデータ内蔵**
   - 試合一覧に、添付ノートの試合（10/18 vs 上智 第4セット 25-22）があらかじめ登録されており、いつでも開いて手書きノート通りのジグザグ折れ線グラフを確認できます。

## 🚀 GitHub Pagesで無料公開してリンクを共有する手順

### ステップ 1: GitHubでリポジトリを作成
1. [GitHub](https://github.com/) で「New repository」をクリック。
2. 名前（例: `volley-score`）を入力し、**Public** を選択して作成。

### ステップ 2: ファイルをアップロード (Push)
以下のファイルをリポジトリに追加します：
- `index.html`
- `style.css`
- `app.js`
- `README.md`

### ステップ 3: GitHub Pagesを有効化する
1. リポジトリの **Settings** ➔ **Pages** を開きます。
2. Branch を「`main`」にして「Save」をクリックします。

### ステップ 4: リンク（URL）をチームに共有！
1分ほどで専用URL（`https://ユーザー名.github.io/volley-score/`）が発行され、全員がスマホから利用できるようになります！
